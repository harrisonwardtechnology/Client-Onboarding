# Legal

**Not legal advice. Not written by a lawyer. Have a real lawyer review anything you sign.**

What this folder does is tell you which documents usually exist, what each one is for, and which clauses cause the most trouble later. That is knowledge, not advice.

| File | What it covers |
|---|---|
| `document-checklist.md` | The papers that should exist before work starts |
| `scope-boundaries.md` | The in scope and out of scope language that prevents arguments |
| `authorization-letter-template.md` | Written permission before you touch anything |

## The one rule

**Nothing starts before the paperwork is done.** Not a small favour, not a quick look, not a friendly diagram review. The moment you do work without an agreement, every later conversation about scope and payment is harder.
