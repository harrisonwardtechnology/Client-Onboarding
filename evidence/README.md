# Evidence

The documents you ask for, why each one matters, and what to do when it does not exist.

| File | Use it for |
|---|---|
| `document-request-list.md` | The single list you send on day one |

## The rule

**Send one list, once, with a deadline and an owner per line.** Requesting documents in dribs and drabs is the fastest way to make an engagement feel endless.

## The other rule

**"It does not exist" is a finding, not a failure.** Say so plainly and without drama. Half the value of the request list is discovering what is missing.
