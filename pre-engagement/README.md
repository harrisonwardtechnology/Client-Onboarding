# Pre-engagement

Before you quote. Before you sign. Before you have any obligation to be nice about it.

The goal of this stage is not to win the work. It is to find out whether the work is winnable and worth winning. A bad engagement costs more than an empty week.

| File | Use it for |
|---|---|
| `discovery-questionnaire.md` | The conversation. Send ahead or ask live |
| `scoping-worksheet.md` | Turning answers into hours and a price |
| `go-no-go-scorecard.md` | Deciding honestly, before you talk yourself into it |
| `red-flags.md` | The patterns that predict a bad engagement |
| `qualifying-call-script.md` | Thirty minutes, first call, no slides |

## Order

1. Qualifying call. Thirty minutes. Find the real driver
2. Send the discovery questionnaire. Give them a week
3. Score it with the go or no-go scorecard
4. Scope it. Price it
5. If it fails the scorecard, say no early and warmly. Refer them somewhere better
