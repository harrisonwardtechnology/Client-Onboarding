# Incident History

What has already gone wrong. Include the near misses. Especially the near misses.

**Owner of this form:** whoever runs IT, with input from finance and HR.

> This is not a blame exercise. Past incidents are the single best predictor of the next one, and they tell us which controls actually matter here rather than in general.

---

## The last two to three years

Repeat this block for each incident. One line each is fine.

| Field | Answer |
|---|---|
| Roughly when? | |
| What happened, in plain words? | |
| How did you find out? (Alert, a customer, a bank, an employee, an attacker telling you) | |
| What was affected? | |
| What did it cost? Include time, not just money | |
| Who was involved in the response? | |
| Did you notify anyone? Customers, regulators, insurer, police | |
| What changed afterward? | |
| Would it work again today? | |

**Why the last two questions:** an incident with no change afterward is a control gap that is still open. That is a finding you already own.

## Categories worth prompting on

People forget these when asked "have you had an incident." Ask them one by one.

- [ ] Someone clicked a phishing link and entered credentials
- [ ] A fake invoice or bank detail change nearly got paid, or did get paid
- [ ] An email account was accessed by someone else
- [ ] Ransomware, or a ransomware scare
- [ ] A laptop or phone lost or stolen
- [ ] A departing employee took files
- [ ] Data sent to the wrong recipient
- [ ] A vendor of yours had a breach that touched your data
- [ ] A website or app defaced, scraped, or abused
- [ ] An outage caused by a change nobody reviewed
- [ ] A cloud bucket, share, or link that was public and should not have been
- [ ] Someone found credentials in code or a shared document
- [ ] A physical incident. Someone got into a building or a room they should not have

**Why:** wire fraud and business email compromise are the ones companies do not think of as "security incidents." They are usually the most expensive thing that has actually happened.

## How you would respond today

| Question | Answer |
|---|---|
| Who gets called first if something happens at 2am on a Sunday? | |
| Is that number written somewhere reachable if email is down? | |
| Do you have an incident response retainer? With whom? | |
| Does your insurer require you to use their panel firm? | |
| Who is allowed to talk to customers or press? | |
| Who can approve paying an extortion demand, and have you thought about it? | |

**Why:** the first hour of an incident is spent finding people. Every minute of that is preventable. See [IR-First-24-Hours](https://github.com/HarrisonWard/IR-First-24-Hours).
