# Compliance Drivers

What actually forces your hand, and by when. Most companies list frameworks they think apply. The thing that bites first is usually a customer contract nobody has read.

**Owner of this form:** whoever owns legal or contracts, with help from sales.

---

## 1. Customer contracts

| Question | Answer |
|---|---|
| Do any signed customer contracts contain security terms? | |
| Which customers, and can we read the clauses? | |
| Do any require a certification by a date? | |
| Do any require breach notification within a set number of hours? | |
| Do any give the customer a right to audit you? | |
| Has a customer sent a security questionnaire in the last year? Can we see it? | |
| Is a deal currently stuck on security review? | |

**Why:** contractual obligations are enforceable today and specific. Frameworks are aspirational until a contract points at one. Start here.

---

## 2. Formal frameworks and regulations

Tick what applies. Then answer the two questions under each ticked box.

- [ ] **SOC 2** - Type I or II? Target date? Auditor selected?
- [ ] **ISO 27001** - Certification or alignment? Which certification body?
- [ ] **PCI DSS** - Which SAQ level? Do you touch card data or redirect it?
- [ ] **HIPAA** - Covered entity or business associate? Do you have BAAs?
- [ ] **GDPR / UK GDPR** - Any EU or UK data subjects, including your own employees? Named DPO?
- [ ] **US state privacy** - Which states? Do you sell or share personal data as defined?
- [ ] **CMMC / DFARS** - Which level? Is there a CAGE code and an SPRS score?
- [ ] **FERPA** - Student data, and from which institutions?
- [ ] **NERC CIP / TSA / sector specific** - Which one, and who is the regulator?
- [ ] **Nothing formal** - but customers keep asking

| Question | Answer |
|---|---|
| Which single item above has the nearest hard deadline? | |
| Who is accountable for it internally? | |
| What happens if you miss it? | |

**Why:** most companies can only really move on one framework at a time. Pick the one with teeth and a date. The rest follow, because the controls overlap heavily.

## 3. Cyber insurance

| Question | Answer |
|---|---|
| Do you carry a cyber policy? Which carrier? | |
| Coverage limit and deductible | |
| When is renewal? | |
| Can we see the last application you submitted? | |
| Did the carrier require anything specific? (MFA, EDR, backup testing, training) | |
| Have you attested to anything you are not actually doing? | |

**Why:** the last question matters more than the rest. A claim denied for a false attestation is worse than no policy. If the answer is yes, fixing it is urgent and we will say so plainly, without judgement.

---

## 4. Prior assessments

| Question | Answer |
|---|---|
| Have you been audited or assessed before? By whom, and when? | |
| Can we read the report, even if the findings are bad? | |
| Which findings were fixed? Which were not? | |
| Was there a management response or a remediation plan? | |
| Any open findings with a due date? | |

**Why:** an unfixed finding from two years ago is the cheapest thing on your roadmap. It is already documented, already agreed, and already embarrassing.
