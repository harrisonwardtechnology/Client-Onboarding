# Weekly Status Report Template

Five bullets. Same five every week. Never longer than one screen.

Send it the same day and time each week. Predictability is the point.

---

## Template

> **[Client] security engagement, week [N]**
> **Date:** [date]
>
> **1. What done looks like**
> [The goal, in the client's words, unchanged from kickoff. Restated every single week.]
>
> **2. Done this week**
> - [Specific thing, with a result, not an activity]
> - [Specific thing]
> - [Specific thing]
>
> **3. Next week**
> - [Specific thing]
> - [Specific thing]
>
> **4. Blocked**
> - [What is blocked] - owner: [name] - since: [date]
> - (Or: nothing blocked this week)
>
> **5. Decisions I need from you**
> - [Decision] - needed by: [date] - if not decided by then: [consequence]
> - (Or: no decisions needed this week)

---

## Rules that make it work

**Restate the goal every week.** It looks repetitive. It is the cheapest defence against drift there is.

**Write results, not activities.** "Reviewed identity configuration" is an activity. "Found 14 admin accounts, 6 belong to people who left" is a result. Only one of those makes someone read the next email.

**Name the blocker owner.** Never write "waiting on IT." Write the person's name and the date it started. Vague blockers stay blocked.

**Attach a consequence to every decision.** "If not decided by Friday, the policy review moves to week 9." This is not a threat. It is information the sponsor needs to prioritize.

**Say when nothing is blocked.** Explicitly. A status report with no blocked section reads like you forgot to check.

**Never bury bad news in bullet three.** If something is going wrong, it goes at the top with a sentence of plain explanation.

---

## When to break the format

Once. If something serious happens, do not send a status report. Call, then send a short email that says what happened, what you recommend, and what you need.

**Why:** the format's value is that it is boring. Breaking it is a signal in itself, and it only works if you never break it for small things.
