# Offboarding

The end of the engagement. Done properly, this is where repeat work comes from.

| File | Use it for |
|---|---|
| `handover-checklist.md` | Leaving them able to run it without you |
| `data-destruction.md` | Giving back and deleting what you held |

## The principle

**Leave the program better than you found it, and leave them able to run it.**

A consultant who makes themselves indispensable has failed, and the client will eventually notice. A consultant who leaves a working program gets called back for the next thing, and recommended to three other companies.
