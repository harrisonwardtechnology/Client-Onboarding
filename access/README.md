## The one rule

**Ask for read, not admin.**

You are there to see the environment, not change it. Read access is easier to approve, faster to grant, and it means you can never be blamed for an outage. If you genuinely need to change something later, ask then, for that thing, with a reason.

Consultants who ask for global admin on day one get delayed by three weeks and deserve it.
