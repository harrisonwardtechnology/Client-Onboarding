# RACI

Who does what, so nothing sits unowned for three weeks while everyone assumes someone else has it.

**R** Responsible, does the work. **A** Accountable, one person, owns the outcome. **C** Consulted, gives input. **I** Informed, told afterward.

**Rule:** exactly one A per row. If you cannot name one, the task is not really owned.

---

## Engagement level

| Activity | Consultant | Internal owner | IT lead | Sponsor | Legal | HR |
|---|---|---|---|---|---|---|
| Grant access | C | R | A | I | | |
| Provide documents | C | A | R | I | C | C |
| Schedule interviews | C | A | I | I | | R |
| Conduct assessment | A/R | C | C | I | | |
| Produce findings | A/R | C | C | I | | |
| Decide what gets fixed | C | R | C | A | | |
| Fund remediation | C | C | I | A | | |
| Implement fixes | C | R | A | I | | |
| Report to board | R | C | I | A | | |
| Approve policy changes | R | C | C | A | C | C |
| Communicate to staff | C | R | I | A | | A |

Adjust to fit. The point is not this exact grid. The point is that every row has one A.

---

## The rows people forget

- **Chasing people who do not respond.** Someone has to own this and it should not be the consultant. The internal owner is A
- **Deciding what does not get fixed.** Accepting risk is a decision. It needs an accountable name and a date to revisit
- **Telling staff what is changing.** Security changes that surprise people get worked around. HR and the sponsor own this together
- **Keeping the risk register current after you leave.** Name the A before the engagement ends, not on the last day

---

## How to make it stick

1. Fill it in during kickoff, on screen, with everyone watching
2. Say each accountable name out loud and get a verbal yes
3. Send it in the recap email within 24 hours
4. Put it at the top of the shared folder
5. When something stalls, do not chase. Point at the row and ask the A what they need

**Why point rather than chase:** chasing makes you the problem. Pointing at a grid the room agreed to makes the grid the problem, and the A fixes it.
